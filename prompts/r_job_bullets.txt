Under "PREVIOUS EXAMPLES" below is a list of achievements from a previous job role that are listed in my resume.  The text in this list represents the "default" version of how each description is worded, but this can be adjusted to be more relevant to the job being applied for.  The order in which the achievements are listed is also customized.
Your task is to help me to customize this list of achievements for the resume version I use to apply for the new job posting.  Please follow this process:
1. Determine the order in which the achievements should appear, so that those most relevant ones are closest to the top of the list.  Assign each achievement a ranking number to indicate where it should be placed in the final list.
2. For each achievement, in the order they appear in the PREVIOUS EXAMPLES list, generate the output using this sub-process:
(a) Decide if there would be significant benefit to updating the default wording to better align with the job posting.  Limit such adjustments to small changes to words or phrases to better reflect the job posting in terms of language and emphasis; they should not materially change the meaning and scope of the original text.  Adjustments should not cause a large net increase in the overall length of the string; only recommend adding words if you can also recommend ways to balance it out by removing or shortening other parts of the description.
(b) If the benefit of making such a change is not significant, return the string "NO CHANGES\n" + the default wording for that achievement + "\n" + the ranking number for that achievement.
(c) Otherwise, return the string "RECOMMEND:" + a description of the specific changes you would recommend (e.g. word replacements, added words/phrases, removed words)+ "\n" + the default wording for that achievement + "\n" + the ranking number for that achievement.
When finished, you should have generated output for each achievement in the PREVIOUS EXAMPLES list.  Please insert "\n\n" between each of these outputs.
